Menggunakan display OLED I²C

Display membuat sistem embedded lebih mudah diamati tanpa membuka serial monitor. OLED SSD1306 I²C merupakan contoh yang populer untuk latihan komunikasi dan antarmuka.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Rangkaian dasar

OLED I²C umumnya memiliki VCC, GND, SCL, dan SDA. Tegangan kerja modul berbeda-beda. Pastikan tegangan suplai serta level logika kompatibel.

Menyiapkan driver

Beberapa firmware menyertakan driver tertentu, namun banyak board memerlukan berkas driver SSD1306 yang disalin ke filesystem. Gunakan driver yang sesuai implementasi MicroPython dan resolusi layar.

from machine import Pin, I2C
import ssd1306

i2c = I2C(0, scl=Pin(22), sda=Pin(21))
oled = ssd1306.SSD1306_I2C(128, 64, i2c)
oled.fill(0)
oled.text("MicroPython", 0, 0)
oled.text("OLED aktif", 0, 16)
oled.show()

Menampilkan nilai sensor

suhu = 27.5
oled.fill(0)
oled.text("Monitoring", 0, 0)
oled.text("Suhu: {:.1f} C".format(suhu), 0, 20)
oled.show()

Masalah umum

  • Alamat I²C salah: lakukan i2c.scan().
  • Layar kosong: periksa alamat, wiring, kontras, dan driver.
  • Karakter tidak tampil: periksa resolusi dan font driver.

Contoh pin GPIO 21/22 lebih umum pada sejumlah board ESP32; gunakan pinout perangkat yang benar.
