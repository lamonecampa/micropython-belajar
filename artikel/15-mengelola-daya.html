Manajemen daya dan deep sleep

Perangkat IoT bertenaga baterai membutuhkan strategi penggunaan energi. Deep sleep dapat mengurangi konsumsi, tetapi rancangan harus mempertimbangkan waktu bangun, periferal, regulator, dan arus bocor.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Mode operasi

Perangkat dapat bekerja aktif, idle, light sleep, atau deep sleep bergantung platform. Nama API dan kemampuan wake-up tidak identik di semua port MicroPython.

import machine
from time import sleep

print("Perangkat akan tidur")
sleep(1)
machine.deepsleep(60_000)  # milidetik pada ESP32 tertentu
Contoh ini spesifik platform. Pin wake-up, waktu tidur maksimum, dan perilaku reset berbeda antar chip. Uji pada model board yang benar sebelum deployment.

Strategi hemat energi

  • Matikan periferal yang tidak dipakai.
  • Kurangi frekuensi sampling dan transmisi.
  • Gunakan deep sleep ketika aplikasi memungkinkan.
  • Pilih regulator dengan quiescent current rendah.
  • Ukur konsumsi nyata memakai multimeter atau power analyzer.

Perhitungan baterai sederhana

Estimasi kasar waktu operasi dapat dihitung dari kapasitas baterai dibagi arus rata-rata. Hasil nyata lebih rendah karena efisiensi regulator, temperatur, kondisi baterai, dan pola beban.

kapasitas_mAh = 2000
arus_rata_rata_mA = 20
jam_teoritis = kapasitas_mAh / arus_rata_rata_mA
print("Jam teoritis:", jam_teoritis)

Latihan

Rancang siklus bangun, baca sensor, kirim data, dan tidur. Bandingkan perkiraan baterai dengan pengukuran.
