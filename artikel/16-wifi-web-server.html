Wi-Fi dan web server sederhana

Dengan Wi-Fi, mikrokontroler dapat menjadi klien jaringan atau menyediakan layanan HTTP sederhana. Kita mulai dengan koneksi sebagai station lalu membuat server minimal.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Menghubungkan ke access point

import network
import time

SSID = "NAMA_WIFI"
PASSWORD = "KATA_SANDI"
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect(SSID, PASSWORD)

for _ in range(20):
    if wlan.isconnected():
        break
    time.sleep(1)

if wlan.isconnected():
    print("IP:", wlan.ifconfig()[0])
else:
    print("Koneksi gagal")

Ganti kredensial dan jangan unggah kata sandi ke repository publik. Simpan konfigurasi di file yang tidak dilacak Git atau mekanisme provisioning aman.

Server HTTP dasar

import socket

addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
s = socket.socket()
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
s.bind(addr)
s.listen(1)
print("Server siap")

while True:
    conn, client = s.accept()
    request = conn.recv(1024)
    response = (b"HTTP/1.1 200 OK\r\n"
      b"Content-Type: text/plain\r\nConnection: close\r\n\r\n"
      b"MicroPython aktif")
    conn.send(response)
    conn.close()

Akses dari browser

Buka alamat IP yang ditampilkan board pada browser perangkat lain dalam jaringan yang sama. Jika router mengaktifkan client isolation atau firewall, koneksi dapat diblokir.

Batas keamanan

Server contoh ini belum memiliki autentikasi, validasi request lengkap, TLS, atau pembatasan akses. Gunakan hanya untuk eksperimen jaringan lokal, bukan membuka kontrol aktuator ke internet.

Latihan

Ubah respons menjadi halaman HTML sederhana dan tampilkan status board. Tambahkan penanganan timeout dan pastikan socket selalu ditutup.
