Memasang firmware MicroPython

Flash ESP32 dan ESP8266 dengan metode grafis atau command line. Pastikan target chip dan file firmware benar sebelum menulis flash.

MICROPYTHON BELAJAR · 8 MENIT BACA

Konsep flashing

Flashing adalah proses menulis firmware ke memori flash mikrokontroler. Untuk perangkat Espressif, tool yang umum digunakan adalah esptool. Thonny juga menyediakan antarmuka untuk memasang firmware pada banyak board.

Metode A: melalui Thonny

  1. Instal dan buka Thonny.
  2. Hubungkan board melalui kabel USB data.
  3. Buka menu Tools → Options → Interpreter.
  4. Pilih interpreter MicroPython dan port serial yang sesuai.
  5. Gunakan opsi untuk memasang atau memperbarui firmware jika tersedia. Pilih target board dan berkas firmware yang benar.
  6. Tunggu proses selesai, lalu hubungkan kembali interpreter.

Metode B: command line untuk ESP

Pasang esptool pada Python komputer:

python -m pip install --upgrade esptool

Periksa apakah perangkat terdeteksi (ganti port sesuai komputer):

python -m esptool --port COM5 chip_id

Menghapus flash untuk instalasi bersih:

python -m esptool --port COM5 erase_flash
Perhatian: erase_flash menghapus isi flash termasuk program dan data filesystem. Cadangkan data penting.

Flash ESP8266

Untuk build ESP8266 yang sesuai, alamat flash umumnya 0. Periksa instruksi khusus pada halaman firmware varian yang diunduh.

python -m esptool --port COM5 --baud 460800 write_flash --flash_size=detect 0 firmware-esp8266.bin

Flash ESP32

Alamat dan susunan image bergantung keluarga chip serta format firmware. Pada build ESP32 klasik tertentu, alamat image adalah 0x1000. Jangan menganggap alamat ini berlaku untuk seluruh keluarga ESP32, S2, S3, C3, atau C6. Ikuti instruksi tepat pada halaman download.

python -m esptool --port COM5 --baud 460800 write_flash 0x1000 firmware-esp32.bin

Verifikasi setelah flashing

Buka REPL pada kecepatan serial yang sesuai, biasanya 115200 baud. Tekan reset pada board. Jika interpreter aktif, kamu akan melihat prompt >>> atau pesan versi MicroPython.

import sys
print(sys.implementation)
print(sys.platform)

Masalah yang sering muncul

  • Failed to connect: coba kabel data lain, tutup aplikasi serial lain, turunkan baud rate, atau masuk ke mode bootloader sesuai board.
  • Wrong boot mode: gunakan tombol BOOT/RESET sesuai petunjuk board.
  • Firmware tidak cocok: periksa ulang varian chip, bukan hanya nama keluarga produk.
  • Port sibuk: tutup Thonny, serial monitor, atau terminal lain yang sedang membuka port.

Latihan

Catat model board, nama firmware, versi MicroPython, port serial, dan hasil verifikasi.
