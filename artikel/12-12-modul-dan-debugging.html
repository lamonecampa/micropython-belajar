Modul, fungsi, dan debugging

Ketika program tumbuh, kode panjang dalam satu file sulit dirawat. Pecah fungsi berdasarkan tanggung jawab dan gunakan pesan error untuk menemukan akar masalah.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Memecah kode menjadi fungsi

def hitung_rata_rata(data):
    if not data:
        return None
    return sum(data) / len(data)

print(hitung_rata_rata([25, 26, 27]))

Menggunakan modul

Simpan fungsi terkait dalam file tersendiri. Misalnya sensor.py berisi fungsi pembacaan, lalu impor dari main.py. Pastikan semua file berada di filesystem perangkat atau lokasi impor yang benar.

def status_suhu(nilai):
    if nilai < 20:
        return "dingin"
    if nilai > 30:
        return "panas"
    return "normal"

Debugging dengan print dan exception

try:
    nilai = 25
    print("DEBUG nilai =", nilai)
    hasil = 100 / (nilai - 25)
except ZeroDivisionError as err:
    print("Operasi tidak valid:", err)

Strategi troubleshooting

  1. Reproduksi error dengan langkah sekecil mungkin.
  2. Baca traceback dari baris paling bawah ke atas.
  3. Periksa pin, wiring, tegangan, dan jenis sensor.
  4. Uji modul secara terpisah sebelum integrasi.
  5. Catat versi firmware dan board saat bug ditemukan.

Latihan

Buat program sensor tiruan yang menghasilkan nilai, klasifikasikan statusnya melalui fungsi, dan tangani input yang tidak valid.
