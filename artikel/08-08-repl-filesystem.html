REPL dan filesystem MicroPython

REPL adalah pintu masuk untuk bereksperimen secara interaktif. Setelah kode stabil, simpan ke filesystem board agar program dapat dijalankan mandiri.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Memahami REPL

REPL adalah singkatan dari Read-Eval-Print Loop. Interpreter membaca perintah, menjalankannya, lalu menampilkan hasil. Prompt biasanya ditandai >>>.

>>> 10 * 4
40
>>> import sys
>>> print(sys.platform)

REPL cocok untuk memeriksa pin, menguji sensor, dan memahami modul. Tekan Ctrl+C untuk menginterupsi program. Ctrl+D pada banyak port melakukan soft reset.

Filesystem internal

MicroPython menyediakan filesystem pada flash untuk menyimpan file. Ruang tersedia bergantung layout firmware dan kapasitas perangkat. Daftar isi dapat diperiksa melalui modul os pada port yang mendukung.

import os
print(os.listdir())

boot.py dan main.py

boot.py dijalankan lebih dulu untuk inisialisasi singkat, sedangkan main.py digunakan untuk aplikasi utama. Hindari membuat boot.py tidak pernah selesai karena dapat mengganggu proses startup.

Transfer file dengan mpremote

Instal tool pada komputer:

python -m pip install --upgrade mpremote

Salin file ke perangkat (contoh port Windows):

mpremote connect COM5 fs cp main.py :main.py

Sintaks dan dukungan filesystem dapat bervariasi menurut versi tool dan port. Periksa mpremote --help jika perlu.

Backup sebelum eksperimen

Simpan salinan program di komputer atau Git. Menghapus firmware atau melakukan erase flash dapat menghilangkan filesystem internal.
