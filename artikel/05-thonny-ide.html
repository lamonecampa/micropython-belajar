Menggunakan Thonny IDE

Editor ramah pemula untuk menulis dan menjalankan kode langsung pada board MicroPython.

Mengapa Thonny?

Thonny menggabungkan penulisan kode, REPL, pemilihan interpreter, dan transfer berkas. Ini membuat proses belajar lebih sederhana.

Konfigurasi interpreter

  1. Instal Thonny dari situs resminya.
  2. Hubungkan board ke komputer.
  3. Buka Tools → Options → Interpreter.
  4. Pilih MicroPython sesuai perangkat, misalnya ESP32 atau ESP8266.
  5. Pilih port serial yang muncul pada sistem.
  6. Terapkan konfigurasi dan tunggu koneksi.

Uji melalui Shell

print("Belajar MicroPython")
2 ** 5

Jika hasil tampil, komunikasi interpreter berjalan. Kamu dapat mengetik perintah satu per satu atau mengirim kode dari editor.

Menjalankan file pertama

Buat berkas baru dan simpan sebagai main.py pada perangkat MicroPython, bukan hanya pada komputer. Jalankan dengan tombol Run.

import time

for angka in range(5):
    print("Hitungan:", angka)
    time.sleep(1)

Filesystem board

Gunakan panel file Thonny untuk membedakan file komputer dan file pada perangkat. main.py pada filesystem board akan dijalankan saat boot.

Tips mengatasi masalah

  • Jika port tidak terdeteksi, periksa kabel dan driver.
  • Jika port sedang digunakan, tutup serial monitor lain.
  • Jika program loop terus berjalan, tekan Ctrl+C pada Shell.
  • Jika board tidak merespons, reset board dan pilih interpreter/port kembali.
