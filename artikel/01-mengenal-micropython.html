Mengenal MicroPython

Gerbang masuk ke dunia pemrograman mikrokontroler. Kenali cara kerja MicroPython, kapan tepat digunakan, dan bagaimana memulai tanpa terjebak pada satu jenis board.

MICROPYTHON BELAJAR · 6 MENIT BACA

Apa itu MicroPython?

MicroPython adalah implementasi bahasa Python 3 yang disederhanakan dan dioptimalkan untuk perangkat dengan sumber daya terbatas. Program dijalankan pada mikrokontroler, bukan sekadar mengirim perintah dari komputer. Setelah program disimpan pada flash perangkat, board dapat menjalankannya secara mandiri ketika dinyalakan.

MicroPython menyediakan modul untuk mengakses perangkat keras, misalnya machine untuk pin dan periferal, network untuk konektivitas pada port yang mendukung jaringan, serta pustaka standar yang disesuaikan dengan kapasitas perangkat.

Mengapa memilih MicroPython?

  • Siklus eksperimen cepat: kode dapat diuji melalui REPL tanpa kompilasi seperti alur C/C++ konvensional.
  • Sintaks mudah dibaca: cocok untuk pembelajaran Python, STEM, prototipe, dan otomasi.
  • Lintas perangkat: konsep dasar dapat digunakan pada ESP32, ESP8266, RP2040, STM32, dan sejumlah board lain.
  • Akses hardware: tersedia antarmuka untuk GPIO, PWM, ADC, I²C, SPI, UART, dan periferal lain sesuai port.
Catatan penting: MicroPython bukan Python desktop versi lengkap. Tidak semua paket PyPI dapat dipasang ke board. RAM, flash, dukungan port, dan implementasi modul membatasi fitur yang tersedia.

Bagaimana alur kerjanya?

  1. Pilih board yang didukung dan identifikasi varian chip serta kapasitas flash.
  2. Pasang firmware MicroPython yang sesuai ke memori perangkat.
  3. Hubungkan komputer melalui USB/serial dan buka REPL menggunakan IDE atau terminal.
  4. Tulis kode, uji, lalu simpan berkas ke filesystem perangkat.
  5. Gunakan main.py untuk program yang dijalankan otomatis saat board boot.

Perangkat apa yang bisa digunakan?

ESP32 cocok untuk eksperimen Wi-Fi dan Bluetooth. ESP8266 berguna untuk proyek Wi-Fi sederhana, meski RAM dan sumber dayanya lebih terbatas. Raspberry Pi Pico/RP2040 cocok untuk dasar elektronika dan kendali. Beberapa board Arduino modern juga memiliki dukungan MicroPython resmi, tetapi Arduino Uno klasik tidak otomatis termasuk di dalamnya.

Contoh pertama

Setelah terhubung ke REPL, ketik perintah berikut:

REPL
print("Halo, MicroPython!")
print(2 + 3)

Hasil yang diharapkan:

Halo, MicroPython!
5

Perintah tersebut menampilkan teks dan hasil operasi sederhana. Kita sudah memastikan interpreter berjalan dan komunikasi serial berfungsi.

MicroPython atau Arduino C++?

MicroPython unggul untuk pembelajaran, validasi ide, dan prototipe cepat. Arduino C++ atau ESP-IDF lebih tepat ketika proyek membutuhkan kontrol tingkat rendah, pustaka khusus, determinisme waktu yang ketat, atau performa maksimal. Pilihan bahasa adalah keputusan rekayasa, bukan perlombaan fan club.

Latihan

  1. Sebutkan tiga alasan MicroPython menarik untuk prototipe.
  2. Apa perbedaan interpreter MicroPython pada board dengan Python yang berjalan di komputer?
  3. Identifikasi model board dan chip yang kamu miliki. Cari apakah tersedia firmware MicroPython untuk model tersebut.
