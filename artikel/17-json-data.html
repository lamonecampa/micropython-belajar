JSON dan pertukaran data

JSON memudahkan pengiriman data sensor dan status perangkat melalui HTTP atau MQTT. Namun, ukuran payload serta konsumsi RAM perlu dipertimbangkan pada mikrokontroler.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Membuat struktur data

import json

data = {
    "device_id": "node-01",
    "temperature": 27.4,
    "humidity": 68,
    "online": True
}
payload = json.dumps(data)
print(payload)

Membaca JSON

import json
payload = '{"temperature": 27.4, "humidity": 68}'
obj = json.loads(payload)
print(obj["temperature"])

Rancang skema konsisten

Tentukan nama field, tipe data, satuan, timestamp, dan identitas perangkat. Jangan mengirim temperatur tanpa menjelaskan satuannya.

Hemat memori

  • Jangan menyimpan payload besar tanpa kebutuhan.
  • Gunakan sampling dan batching sesuai RAM.
  • Hapus referensi data yang tidak lagi dibutuhkan.
  • Uji ukuran payload pada board sebenarnya.

Latihan

Buat payload berisi ID perangkat, nilai sensor, satuan, dan status koneksi. Parse kembali payload lalu validasi field wajib.
