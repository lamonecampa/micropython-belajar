Penyimpanan data lokal

Tidak semua data harus langsung dikirim ke cloud. Penyimpanan lokal dapat menjadi buffer saat jaringan terputus atau menyimpan konfigurasi perangkat.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Menyimpan konfigurasi

{"device_id":"node-01","sample_interval":60}

File JSON dapat dibaca dari filesystem board. Pastikan penulisan tidak terlalu sering sehingga mempercepat keausan flash.

import ujson
with open("config.json", "r") as file:
    config = ujson.load(file)
print(config["device_id"])

Logging sederhana

from time import time

with open("data.csv", "a") as file:
    file.write("{},{}\n".format(time(), 27.5))

Strategi penyimpanan

  • Gunakan ring buffer atau batas ukuran file.
  • Batch write bila sesuai kebutuhan.
  • Validasi konfigurasi saat startup.
  • Gunakan RTC atau sinkronisasi waktu jika timestamp penting.
  • Rencanakan pemulihan setelah listrik terputus.

Filesystem bukan database besar

Flash perangkat memiliki kapasitas dan umur tulis terbatas. Untuk riwayat jangka panjang, gunakan server atau penyimpanan eksternal yang sesuai.

Latihan

Buat logger sederhana yang menyimpan timestamp dan pembacaan sensor. Buat mekanisme rotasi atau penghapusan data tertua saat kapasitas mencapai batas.
