GPIO: LED dan tombol

GPIO menjadi jembatan antara program dan dunia fisik. Kita mulai dengan LED sebagai output dan tombol sebagai input digital.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Konsep GPIO

GPIO (General Purpose Input/Output) adalah pin yang dapat dikonfigurasi sebagai masukan atau keluaran. Nomor GPIO internal tidak selalu sama dengan label pin pada board. Lihat pinout sebelum menghubungkan kabel.

Mengendalikan LED

Hubungkan LED seri dengan resistor pembatas arus ke pin GPIO dan GND sesuai polaritas. Jangan menghubungkan LED langsung tanpa resistor.

from machine import Pin
from time import sleep

led = Pin(2, Pin.OUT)
while True:
    led.on()
    sleep(0.5)
    led.off()
    sleep(0.5)
GPIO 2 bukan pin universal. Beberapa board memakai LED onboard aktif-rendah, pin berbeda, atau tidak menyediakan LED bawaan. Sesuaikan dengan pinout perangkat.

Membaca tombol

Gunakan resistor pull-up internal jika board dan pin mendukung. Tombol menghubungkan pin input ke GND ketika ditekan, sehingga pembacaan menjadi 0.

from machine import Pin
from time import sleep_ms

button = Pin(4, Pin.IN, Pin.PULL_UP)
while True:
    if button.value() == 0:
        print("Tombol ditekan")
        sleep_ms(200)  # debounce sederhana

Debouncing dan latihan

Kontak mekanis dapat menghasilkan beberapa transisi cepat. Delay sederhana cukup untuk demo; aplikasi andal dapat memakai state machine atau timer.

  1. Ubah interval LED menjadi satu detik.
  2. Gunakan tombol untuk menyalakan dan mematikan LED.
  3. Amati logika aktif-rendah dan aktif-tinggi.
