HTTP dan REST API

Selain MQTT, perangkat dapat berkomunikasi dengan server melalui HTTP. Pola REST menggunakan endpoint dan metode seperti GET atau POST untuk bertukar sumber daya.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Konsep request dan response

HTTP request memuat metode, URL, header, dan kadang body. Response berisi status code, header, dan data. Pastikan endpoint dan metode sesuai dokumentasi layanan.

Mengirim data JSON

Contoh berikut menunjukkan pola penggunaan. Endpoint diganti dengan server yang kamu kelola dan library HTTP yang tersedia di firmware.

import ujson
import urequests

payload = {"device": "node-01", "temperature": 27.2}
response = urequests.post(
    "http://192.168.1.20:8000/api/telemetry",
    data=ujson.dumps(payload),
    headers={"Content-Type": "application/json"}
)
print(response.status_code)
response.close()

Penanganan kegagalan

  • Gunakan timeout.
  • Selalu tutup response agar resource dilepas.
  • Periksa status code.
  • Batasi retry dengan backoff.
  • Jangan mengirim kredensial melalui HTTP tanpa perlindungan.

HTTP atau MQTT?

HTTP praktis untuk request-response dan integrasi API web. MQTT lebih cocok untuk aliran pesan publish-subscribe dan telemetry yang perlu disebarkan ke banyak konsumen. Keduanya dapat dipakai bersama.

Latihan

Buat API lokal sederhana untuk menerima telemetry, kirim JSON dari board, lalu simpan timestamp dan identitas perangkat pada server.
