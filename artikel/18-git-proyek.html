Mengelola proyek MicroPython dengan Git

Simpan kode sumber pada komputer dan gunakan Git untuk melacak perubahan. Filesystem mikrokontroler adalah tempat eksekusi, bukan pengganti repository proyek.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Struktur proyek

iot-node/
├── README.md
├── .gitignore
├── src/
│   ├── main.py
│   ├── wifi_config.example.py
│   └── sensors.py
└── tests/
    └── test_logic.py

Perintah dasar Git

git init
git add .
git commit -m "Inisialisasi proyek MicroPython"
git status

Jangan commit rahasia

File berisi SSID, password, token API, dan kredensial broker harus dikecualikan. Sediakan file contoh tanpa secret agar pengguna lain dapat menyalin dan mengisi konfigurasi sendiri.

wifi_config.py
secrets.py
.env
*.log
__pycache__/

Workflow pengembangan

  1. Tulis kode di komputer.
  2. Uji logika umum tanpa hardware sebisa mungkin.
  3. Upload file terpilih ke board.
  4. Uji hardware dan dokumentasikan hasil.
  5. Commit perubahan yang sudah diverifikasi.

Latihan

Buat repository untuk proyek LED dan tombol. Tambahkan README berisi board, wiring, firmware, langkah menjalankan, serta keterbatasan yang diketahui.
