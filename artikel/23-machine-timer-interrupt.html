Timer, interrupt, dan event

Timer dan interrupt berguna untuk merespons peristiwa perangkat keras. Fitur ini kuat tetapi mudah disalahgunakan: handler harus singkat dan aman terhadap keterbatasan runtime.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

Timer periodik

from machine import Timer

def callback(timer):
    print("Tick")

timer = Timer(0)
timer.init(period=1000, mode=Timer.PERIODIC, callback=callback)

Contoh timer dapat berbeda berdasarkan port. Pada sejumlah perangkat, timer ID, callback, dan dukungan interrupt memiliki batasan tertentu.

Interrupt GPIO

from machine import Pin

button = Pin(4, Pin.IN, Pin.PULL_UP)
def pressed(pin):
    print("Tombol berubah")

button.irq(trigger=Pin.IRQ_FALLING, handler=pressed)
Handler interrupt sebaiknya singkat. Hindari operasi file, alokasi memori yang tidak aman, atau komunikasi jaringan dalam ISR. Untuk pekerjaan berat, gunakan flag/queue lalu proses di loop utama.

Polling atau interrupt?

Polling sederhana dan lebih mudah diprediksi untuk banyak kasus. Interrupt berguna ketika kejadian harus segera dideteksi atau polling terlalu boros. Pilih berdasarkan kebutuhan waktu nyata.

Latihan

Deteksi tombol melalui interrupt, set flag, lalu ubah LED pada loop utama. Tambahkan debounce yang sesuai.
