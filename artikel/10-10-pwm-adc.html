PWM dan ADC

PWM digunakan untuk mengatur daya rata-rata ke beban tertentu, sedangkan ADC mengubah tegangan analog menjadi nilai digital.

MICROPYTHON BELAJAR · 6–10 MENIT BACA

PWM

Pulse Width Modulation mengatur rasio waktu sinyal berada pada kondisi aktif. Duty cycle lebih besar umumnya menghasilkan kecerahan LED lebih tinggi. Frekuensi dan rentang duty bergantung port.

from machine import Pin, PWM
from time import sleep

led = PWM(Pin(2), freq=1000)
try:
    for duty in (0, 256, 512, 768, 1023):
        led.duty(duty)  # API ESP8266; cek port
        sleep(1)
finally:
    led.deinit()

API PWM berbeda antar port dan versi firmware. Beberapa port menggunakan rentang 0–65535 atau metode duty_u16().

ADC

ADC membaca tegangan analog dari sensor. Rentang tegangan maksimum tidak boleh diasumsikan sama dengan tegangan catu board. Periksa dokumentasi pin ADC dan gunakan pembagi tegangan bila diperlukan.

from machine import ADC, Pin
# Contoh untuk board ESP32 tertentu; pin dan attenuasi berbeda
adc = ADC(Pin(34))
print(adc.read())

Kalibrasi dan noise

Nilai ADC bukan otomatis satuan volt atau nilai fisik. Gunakan rumus konversi berdasarkan resolusi, referensi tegangan, rangkaian sensor, dan kalibrasi.

Latihan

Atur intensitas LED berdasarkan potensiometer. Catat nilai ADC minimum dan maksimum lalu buat pemetaan ke duty cycle. Jangan menghubungkan tegangan di luar batas pin.
